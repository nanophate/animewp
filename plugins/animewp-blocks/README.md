# AnimeWP Blocks

バージョン1.1.0。任意のcompanion plugin。WordPress 6.6以上・PHP 8.0以上を対象にした、テーマ非依存の静的ブロック4種類です。ビルド操作や追加パッケージは不要です。全装飾の初期値はオフで、内蔵の装飾色は白・黒・灰色のみです。

## 導入

`animewp-blocks` フォルダーを `wp-content/plugins/` に置き、管理画面の「プラグイン」で有効化してください。「AnimeWP」でブロックを検索できます。テーマだけでもサイトを運用でき、このプラグインだけを別テーマで利用することもできます。

有効化・停止・削除で、投稿、固定ページ、オプション、メニュー、リライトルールを変更しません。独自テーブル、独自投稿タイプ、外部フォント、解析処理、外部スクリプト、外部画像、初期コンテンツの生成はありません。選択・入力した画像や動画の配信元には、通常のメディア表示としてブラウザーから接続します。

## ブロック

### `animewp/panel` — パネル

内側に標準ブロックを自由に追加できます。画像、リンク、段落、見出し、カラム、動画などを混在できます。2・3・5列や各列の幅は標準の「カラム」で設定してください。

背景色・文字色・内外余白・ブロック間隔・文字サイズ・行高は標準スタイル設定を使います。テーマが標準UIを制限する場合は、そのテーマの設定が優先されます。標準背景とグローバルスタイルの背景は常にブロック本体に残ります。「装飾背景レイヤーを追加」を明示的にオンにすると、その上に任意色の色面を重ね、境界（波形／斜め）・装飾背景だけの回転・傾斜・不透明度を設定できます。回転は色面を回し、傾斜は色面を斜めにゆがめます。どちらも本文の角度を変えません。装飾面の外側や半透明部分には標準背景が見えます。パネル全体の回転、角丸、パネルの影、文字の影、短い見出しの帯は別途設定できます。標準の影を指定した場合は、その値が追加の影プリセットに優先します。

「折り返す各行に帯」は行ごとに背景を複製し、「余白つきの一枚パネル」は見出し全体を一枚で囲みます。縦書きは任意の短い見出しだけに適用します。40文字を超える見出し、本文、幅781px以下の表示では横書きです。傾斜や回転は隣接要素との間隔を見ながら設定してください。装飾背景の境界・不透明度・傾斜は追加レイヤーにだけ作用し、標準背景そのものを切り抜きません。背景全体を透過した波形にする場合は、標準背景を透明にして装飾レイヤーの色を指定してください。

「パネル全体の回転」は従来どおり、背景とすべての内側ブロックをまとめて回転します。子ブロックの0度は親の回転を打ち消しません。1.1.0では入れ子のパネルが親の装飾変数を誤って引き継がないよう修正しました。たとえば親が4度・子が0度の場合、子にさらに4度が加わることはありませんが、子を含む親全体は4度回転します。各パネルの角度、角丸、帯、背景色面、不透明度、間隔、影の設定はそれぞれのパネルに限定されます。通常の文字色や文字サイズなど、標準CSSの継承は利用できます。

### `animewp/text-group` — 文字グループ

段落・見出し・リスト・標準グループなどをまとめ、そのグループの角度を調整します。内側には標準ブロックを自由に追加できます。別の文字グループや外側に置いた段落の角度は変わりません。文字列の一部分を選択して回転する機能ではありません。

1. パネルの「パネル全体の回転」を0度にします。
2. パネル内で「AnimeWP 文字グループ」を追加し、その内側に傾けたい段落や見出しを置きます。既存ブロックはリスト表示から移動できます。
3. リスト表示や編集画面下の階層から「文字グループ」を選び、「この文字グループの回転」を設定します。範囲は−8〜8度で、0度は水平です。
4. 水平にしたい段落は、同じパネル内で文字グループの外に置きます。別角度の文章を追加する場合は、もう一つ文字グループを並べて、それぞれに角度を設定します。

たとえば、パネル内に「文字グループA：−3度」「通常の段落」「文字グループB：4度」を並べると、通常の段落は水平で、AとBだけが各角度になります。背景だけも傾けたい場合は、パネルの装飾背景レイヤーをオンにして「装飾背景だけの回転」を指定します。

「この文字グループの回転」は幅782px以上、「モバイルの回転」は幅781px以下に適用します。モバイルは読みやすさのため初期値0度で、必要なら−8〜8度で個別に設定できます。文字グループを入れ子にしても回転変数は継承しません。ただし親のパネルや文字グループ自体が回転していれば、内側もその幾何学的な回転を受けます。親に対する角度を設定するため、子を0度にしても親の回転を相殺しません。

回転は表示だけの変更で、読む順・Tab順は変えません。回転した要素のために前後の間隔が自動で広がることはないため、標準の外側余白と内側余白で、折り返し・隣の文章との重なり・フォーカス表示を確認してください。背景・文字色・文字サイズ・行高・ブロック間隔も標準スタイル設定を利用します。編集画面と公開画面で同じ構造とCSSを使用し、画面幅に応じて同じ角度を適用します。

挿入メニューのパターン「AnimeWP ブロック」には「背景と傾いた見出し・水平本文」と「角度の違う2つの文字グループ」を用意しています。前者は背景−2度・見出し−3度・本文0度、後者は文字グループ−3度と4度で、どちらも親パネルは0度です。見本の文章を置き換えて使えます。パターンは利用者が挿入したときだけ本文に入り、有効化だけで投稿を作成・変更しません。

### `animewp/media` — 画像と本文

標準の「画像」と、標準ブロックを自由に追加できる「グループ」を内包します。画像の代替テキスト・リンク・キャプションは標準画像ブロックで編集します。

「読む順」は内側のブロックを実際に並べ替え、保存HTMLの順序、読み上げ順、Tab順、モバイルの表示順を一致させます。デスクトップの左右配置は見た目の構図だけを変更します。幅781px以下では常に保存DOMの順で縦に並びます。画面幅変更時のJavaScriptによるDOM移動はありません。

画像の切り抜きは初期状態ではオフです。有効にするとデスクトップとモバイルの高さ・焦点を個別に設定できます。重ね配置はデスクトップだけに適用します。内側の標準グループで背景色や余白を指定し、画像と文字・キャプションの重なりやコントラストを確認してください。

### `animewp/video` — 動画ダイアログ

メディアライブラリで動画を選ぶか、実際に再生できる動画ファイルのURLを入力します。埋め込みサービスを独自実装するブロックではありません。標準の埋め込みが必要な場合は、別途標準の「埋め込み」ブロックを使えます。

動画、ポスター、字幕はHTTP(S)またはサイト内の絶対パスを受け付けます。スクリプトURL、データURL、資格情報つきURL、プロトコル相対URLは受け付けません。字幕はWebVTTを使用し、動画と同じ配信元で提供してください。異なる配信元の字幕や認証が必要な配信は対象外です。字幕ファイルの配信・MIME設定は運用環境で確認が必要です。

通常の `<video controls preload="none">`、字幕、動画ファイルへのリンク、説明、内側の標準ブロックを保存します。対応ブラウザーでは表示時に同じ動画要素をネイティブの `<dialog>` に一度だけ移し、開くボタンを表示します。クリックで開き、自動再生はしません。ネイティブモーダルがTabフォーカスを閉じ込め、Escapeと閉じるボタンで閉じます。閉じると再生を一時停止し、開くボタンへフォーカスを戻します。モーダルの初期化に失敗する場合は通常の動画に戻します。

JavaScript無効、ネイティブダイアログ非対応、プラグイン停止時は通常の動画・字幕・説明・リンクが残ります。説明文はテキストとして扱います。詳しい文字起こしは内側に標準段落・見出しなどを追加してください。

## 停止・別の形式への移行

保存形式は静的HTMLと `InnerBlocks.Content` です。サーバーで動的に本文を生成しません。停止後も表示側の本文・標準メディアは残り、独自装飾と動画のダイアログ機能が外れます。

編集を続ける場合は、停止前にブロックの変換メニューを使う方法を推奨します。

- パネル → 標準グループ。短い見出しも標準見出しへ変換します。
- 文字グループ → 標準グループ。内側の文章・標準グループ・リンク・ブロック順を保持し、回転を外します。
- 画像と本文 → 標準グループ。画像の設定・キャプション・本文・保存順を保つ最も確実な移行です。
- 画像と本文 → 標準「メディアとテキスト」も選択できます。本文のグループ設定を残し、画像キャプションは本文側の段落へ移します。モバイル焦点・独自の読む順・重ね配置は標準ブロック側の動作へ変わります。画像の特殊なリンクや拡大表示などは再確認してください。
- 動画ダイアログ → 標準グループ内の標準動画・字幕・説明段落・追加ブロック。ダイアログ装飾は外れます。

停止済みの場合は、一時的に再有効化して上記変換を行うか、未対応ブロックのメニューから保存内容をカスタムHTMLとして保持できます（メニュー名は環境により異なります）。投稿を複製して確認すると移行を比較できます。アンインストールで保存内容は削除しません。

## CSSカスタムプロパティ

すべてのCSSは `.wp-block-animewp-panel`、`.wp-block-animewp-text-group`、`.wp-block-animewp-media`、`.wp-block-animewp-video` の内側に限定しています。独自のグローバル変数・HTMLクラス・data属性・スクリプト／スタイルhandleは `animewp` 名前空間に限定しています。PHPは `Animewp\Blocks` 名前空間です。ブロック設定で指定した値は、対応するカスタムプロパティのインライン指定に反映されます。

テーマやサイト側のCSSから、次のプロパティを任意の値で調整できます。パネルと文字グループは各ルートで変数を初期化するため、変更したいブロック本体のセレクターを指定してください。親要素や `:root` から独自装飾変数を継承させる指定は使いません。プラグインには生CSS入力・JavaScript入力・HTML直接実行のUIを設けていません。

| 対象 | プロパティ |
| --- | --- |
| 装飾背景レイヤー | `--animewp-panel-backdrop-background`、`--animewp-panel-opacity`、`--animewp-panel-skew`、`--animewp-panel-backdrop-rotation`（レイヤーがオンの場合に適用） |
| パネル角丸 | `--animewp-panel-radius` |
| パネル全体 | `--animewp-panel-rotation`、`--animewp-panel-box-shadow`、`--animewp-panel-text-shadow`、`--animewp-panel-gap` |
| 見出しの帯 | `--animewp-panel-highlight`、`--animewp-panel-highlight-padding` |
| 文字グループ | `--animewp-text-group-rotation`、`--animewp-text-group-mobile-rotation`、`--animewp-text-group-gap` |
| 画像と本文 | `--animewp-media-image-width`、`--animewp-media-gap`、`--animewp-media-height`、`--animewp-media-mobile-height`、`--animewp-media-focus`、`--animewp-media-mobile-focus` |
| 動画ボタン | `--animewp-video-button-color`、`--animewp-video-button-background`、`--animewp-video-button-radius` |
| ダイアログ | `--animewp-video-dialog-color`、`--animewp-video-dialog-background`、`--animewp-video-dialog-padding` |

## 実装と検証

各 `block.json` が現行ブロックの属性・型・初期値・enumの単一の定義元です。PHPでサーバー登録し、同じメタデータを安全にJSON化して通常の `wp.*` APIでエディター登録します。旧保存形式の読込用定義は、当時の属性・対応機能・保存処理を別途固定して保持しています。`apiVersion: 3`、メタデータの `style` と `editorStyle` により、投稿編集画面とサイトエディターのiframeにもCSSを渡します。保存時はURL・数値範囲・enum・独自色指定を正規化します。

1.1.0のパネル初期値の修正はCSSで行い、既存の保存構造を維持します。新しい装飾背景の回転は初期値0度では保存スタイルを追加しません。不透明度はWordPressのバージョンに左右されない単位なしの文字列で保存します。1.0.0とWordPress 6.6の組合せで保存された `--animewp-panel-opacity:0.7px` などの旧形式も互換定義で読み込めます。編集して保存すると、同じ不透明度を正しく表示できる `0.7` などの単位なし形式に移行します。旧形式の0には元から単位がなく、100%は従来どおりスタイルを省略します。単位なしで保存された1.0.0のブロックもそのまま受け付けます。

文字グループも静的HTMLと内側の標準ブロックを保存し、停止・削除後も文章やリンクを残します。プラグイン更新・表示・編集画面の読込だけでデータベースを書き換えません。投稿の一括更新、グローバルスタイルへの変更はありません。

実装時にJavaScript構文チェック、JSON読み込み、属性default/type/enum整合、APIスタブを用いた保存関数のURL・数値・enum・説明テキストの境界値チェックを確認済みです。APIスタブは実WordPressのvalidation試験の代わりにはなりません。実WordPressでの保存→再読込・サーバー登録、投稿者権限での保存、エディターiframeの見た目、停止後の表示、ネイティブ変換、キーボード操作、実動画と字幕の再生は、統合環境での確認項目です。最低バージョン、複数ブラウザー、支援技術、任意テーマの全組合せは未検証です。
