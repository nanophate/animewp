Carousel, video cards, backdrops, decorations and motion for anime and film sites. Saved content stays readable without the plugin.

== Description ==

Simple blocks that combine into rich sections:

* Carousel: turns any blocks into slides that swipe or cross-fade, with dots, numbers or thumbnails.
* Video Card: a poster and play button that opens YouTube, Vimeo or a video file in a player window. Players load only after the visitor presses play.
* Backdrop: a background layer for a section that follows the current slide or card, or shows an image or looping video.
* Decoration: shapes or images placed anywhere in a section.
* Motion: entrance, hover, loop and parallax effects for every block, applied to a group so inner blocks follow in turn.

Also includes Decorated Panel, Rotated Text, Image & Text and Video Button from 1.x. The interface is translated into Japanese.

== Privacy ==

The plugin does not track visitors. YouTube and Vimeo are contacted only when a visitor presses play, unless a Backdrop is set to play the current video muted. Editors can import a YouTube thumbnail into the Media Library; the server downloads it once from i.ytimg.com.
