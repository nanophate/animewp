# animewp

作品紹介サイトを標準Gutenbergで編集する、単独インストール可能なWordPressブロックテーマです。親テーマや有料ビルダーは必要ありません。

- `themes/animewp/`：通常の投稿・固定ページ・検索・アーカイブと、再利用できる3構成のLP、ヘッダー、セクションのパターン。
- `plugins/animewp-blocks/`：任意の8ブロック（装飾パネル、回転テキスト、画像と本文、動画ボタン、カルーセル、動画カード、背景レイヤー、装飾）とモーション。テーマだけでも利用できます。
- [INSTALL-ja.txt](INSTALL-ja.txt)：ZIP導入、初期編集、更新、停止時の手順。
- [v2の設計](docs/architecture-v2.md)、[任意ブロックの仕様](plugins/animewp-blocks/README.md)、[全体レビューと残作業](docs/review-2026-10.md)。

有効化時にページ、メニュー、公開状態、ホーム設定を変更しません。見本は管理画面でプレビューした後、必要なものだけ新規下書きに取り込みます。同じ見本を再実行すると作成済みページを開きます。本文・画像は見本なので、公開前に自分の内容へ差し替えてください。

外部フォント・解析・外部素材を同梱しません。利用者が入力した画像・動画のURLを表示すると、その配信元へブラウザーが接続します。標準ブロックとブロックのスタイル設定を基本にし、独自ブロックも保存HTMLと内側の標準ブロックを残します。

## 見本と幅の編集

編集画面の「＋ → パターン」に、組み立て方の見本を用意しています。

見本は15種類です。どれも同じテキストスタイル・区画のスタイル・色の役割で作っているため、配色や書体を変えるとすべてが一緒に変わります。挿入後は見出し・段落・画像・ボタンなどを1つずつ選んで編集・移動・削除できます。

| 分類 | 見本 |
| --- | --- |
| animewp：区画の見本（10） | キービジュアル、作品紹介、ストーリー、映像、キャラクター、スタッフ・キャスト、音楽、放送・配信、お知らせ、締めくくり |
| animewp：ページの見本（5） | テーマだけで作る、シンプル、ぼかしから現れる、花びらが舞う、スタイル見本（すべての部品と動き） |

「テーマだけで作る」は補助プラグインなしで使えます。カルーセル・動画カード・背景レイヤー・装飾を含む見本は、必要なブロックが有効なときだけ一覧に表示します。この15種に加え、お問い合わせ・ご利用についての案内ページを用意しています。見本の文章と画像は仮のものです。公開前に差し替えてください。

区画の外枠はブロックツールバーの配置から通常・幅広・全幅を選べます。内側の本文幅はグループのレイアウト設定で調整します。見出しや段落の左・中央・右揃えは各ブロックで設定し、横並び・縦並びや間隔はグループのRow／Stack設定で変えます。親グループより広い全幅にはできないため、画面いっぱいに広げる区画は本文直下へ置いてください。

ヘッダー内のロゴ、サイト名、ナビゲーション、CTAは標準ブロックです。共通ヘッダーを変える場合は「外観 → エディター → デザイン → テンプレートパーツ → ヘッダー」で対象を選び、必要な要素だけ編集・移動します。テンプレートパーツはそれを使うページ全体に反映されます。

動画は補助プラグインの「動画カード」で表示します。ポスターはメディアライブラリーの画像、またはYouTubeのサムネイルを取り込んで使います。訪問者のブラウザーは再生を押すまで動画サービスに接続しません。背景レイヤーで「表示中の動画を無音で再生」を選んだ場合は、背景表示時に接続します。

テーマ更新ではファイルの初期テンプレートを更新しますが、サイトエディターで保存済みのテンプレートやテンプレートパーツはデータベース側に残り、そのまま優先されます。新しい初期レイアウトが自動で反映されない場合は、保存済みの共通パーツを確認し、必要な場合だけ編集してください。

## 対象と確認範囲

最低対象はWordPress 6.6 / PHP 8.0です。CIではPHP 8.0/8.3の構文と、WordPress 6.6 / PHP 8.0・WordPress 7.1 / PHP 8.3の実WordPress統合試験を実行します。保存HTMLの互換性は6.6・7.1の本体エディタースクリプトを使い、独自ブロックとモーション付き標準ブロックで確認します。

今回の確認範囲・再現した問題・残作業は[全体レビュー](docs/review-2026-10.md)にまとめています。実ブラウザーでのiframe編集、実ZIPによる更新前後の保持、支援技術、他プラグインとの組合せは、公開前に追加確認する項目です。[1.xの検証記録](docs/verification.md)は履歴として残し、v2で再実施した証拠とは分けています。

## ソース検査

ホストに必要なのはPython 3.10以上、Node.js 24.18以上、npm 11.16以上、Dockerです。CIはNode.js 24とnpm 11.16.0を使います。PHPとWordPressはDockerで動かすため、PCへのPHP導入は不要です。リポジトリのルートで実行します。

```sh
npm ci
npm ci --prefix tests/serialization
python3 scripts/validate.py --compare
```

`validate.py` は補助プラグインをビルドし（`src/` → `build/`）、PHPをローカルに無ければ `php:8.0-cli` コンテナーで構文検査します。`--compare` は保存HTMLの互換性を `main` と比較します。比較にはWordPress本体のエディタースクリプトが必要なため、先に `npm run env:start`（`@wordpress/env`、localhost:8888）を起動するか、`ANIMEWP_WP_DIR` にWordPressのフォルダーを指定してください。開発の詳しい手順は[補助プラグインのREADME](plugins/animewp-blocks/README.md#開発)にあります。

PHP・JavaScript・Pythonの構文、JSON、メタデータ、必須テンプレート、属性の既定値、外部参照、よく使われる秘密情報の形式、SVG、ZIP構成と再現性を検査します。秘密情報検査は既知形式の検出であり、あらゆる秘密情報の不存在を証明するものではありません。

別ランタイムでPHPを検査する場合だけ、`python3 scripts/validate.py --skip-php`を利用できます。出力にPHPを省略したことが表示されます。`tests/wp-smoke.php`はデータを書き換えるため、使い捨てのWordPressデータベース専用です。

外部参照の例外は機械用JSONスキーマ、SVGのXML名前空間、同梱GPL全文、明示操作後だけ使う動画プロバイダーの許可済みURLです。テスト用URLはインストールZIPに入りません。ローカルQA環境と生成物はソース監査・配布対象から除外します。

## 配布ZIPの作成

```sh
python3 scripts/validate.py
python3 scripts/package.py
```

`artifacts/releases/`へ次を生成します。番号は各パッケージのVersionヘッダーから読み取ります。

- `animewp-2.0.0.zip`：最上位フォルダーは`animewp/`のみ。
- `animewp-blocks-2.0.0.zip`：最上位フォルダーは`animewp-blocks/`のみ。
- `SHA256SUMS`：2つのZIPのSHA-256。

ファイル順、ZIP日時、権限、格納方式を固定しています。同じソースなら環境の更新日時に左右されず同じZIPになります。各ZIPは格納方式を使い、圧縮ライブラリの違いによる出力差を避けます。ソースやQA環境を含むリポジトリ全体をWordPressへアップロードしないでください。

書き込みなしの確認は`python3 scripts/package.py --check`、出力先変更は`--output <出力先>`です。ハッシュは出力先で確認できます。

```sh
cd artifacts/releases
shasum -a 256 -c SHA256SUMS
```

GitHub Actionsは同じソース・パッケージ検査に加え、実WordPressで権限・nonce・下書き取り込み・設定保持・HTTP表示の統合試験を実行します。ActionはコミットSHAへ固定し、通常CIの権限は読み取りだけです。ブラウザーでの操作・見た目の確認は別途必要です。Release作成とWordPressの自動更新は、[更新配布方針](docs/maintenance.md)に記載した次の実装対象です。

## 1.2.0

白・黒・グレーのシンプルな土台を維持します。追加の配色スキンや着せ替え画面はありません。色は標準Global Styles、各ブロックの色設定、追加CSSから調整します。既存の色・書体・本文を有効化や更新だけで変更しません。

WordPress標準Font Libraryの追加書体を利用でき、任意の3用途（英字・大見出し／短いアクセント／等幅文字）にも割り当てられます。書体数の上限は設けません。標準ブロックで編集できる余白の大きいホーム、画像付きフッター、作品紹介、人物プロフィール、放送表、音楽、書籍・商品、手動SNSカードを追加しました。

[1.2の仕様と対応表](docs/v1.2-design.md)、[検証結果](docs/verification.md)、[画像の来歴・容量・ハッシュ](themes/animewp/assets-manifest.json)。

## 2.0.0

- 色は8つの役割に整理し、配色（白黒・夜空・桜・青空・夕暮れ）を「スタイル → パレット」から選べます。
- テキストスタイル（補助見出し・英字ラベル・リード文・キャッチコピー・キャプション・大見出し・英字見出しなど）と区画のスタイルを「スタイル → ブロック」でまとめて編集できます。別画面だった書体設定はなくなりました（1.xの設定は引き続き適用）。
- 補助プラグインに、組み合わせて使う部品「カルーセル」「動画カード」「背景レイヤー」「装飾」と、対応する標準・独自ブロックに付けられる「モーション」を追加しました。
- 見本は57から15に絞り、同じ部品で作った区画10種とページ5種（テーマだけで作るページを含む）にしました。
- ヘッダーの余白はブロック設定に保存し、編集画面と公開画面が一致します。2.0より前に保存したヘッダーは同じ見た目のままです。
- 補助プラグインは`@wordpress/scripts`でビルドし、画面の文言は英語の原文と日本語訳です（保存HTMLの文言は変わりません）。テーマの文言は引き続き日本語です。
- 詳しい変更方法は[テーマ同梱のガイド](themes/animewp/docs/customizing.md)を参照してください。
