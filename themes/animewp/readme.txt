animewp 2.0.2
WordPress 6.6 以上 / PHP 8.0 以上
ライセンス: GPL-2.0-or-later

単独で使えるブロックテーマです。親テーマや補助プラグインは不要です。
外観 → animewp をはじめる、から見本のプレビューと下書き追加を選べます。
有効化だけでは、投稿、メニュー、表示設定を変更しません。
外観 → エディターで、ヘッダー、フッター、テンプレート、配色、書体、テキストスタイルを編集します。
細かな調整方法は docs/customizing.md にあります。
ページ本文は標準ブロックです。画像と仮の文章を公開前に差し替えてください。
複製したセクションの HTML アンカーは、一意になるよう変更してください。

animewp-blocks は、カルーセル、動画カード、背景レイヤー、装飾、モーションなどを加える任意プラグインです。
サイトエディターに保存した変更は、テーマの ZIP 更新より優先されます。
更新前にはファイルとデータベースをバックアップし、検証環境で確認してください。
独自の仮画像を同梱し、外部フォント・解析通信は初期状態では読み込みません。

== Changelog ==

= 2.0.2 =
* スマートフォンでの見出し・短い表示文の折り返しと、画面幅に応じた余白を調整。
* 左右固定メニューの文字詰まりと配置、モバイルメニューの表示を修正。
* 固定ヘッダーの実際の高さをページ内リンクの移動位置に反映し、スクロール時の縮小とアンカーへの直接アクセスを調整。
* 不正なパーセントエンコードを含むURLのアンカーで、表示用スクリプトが例外を起こさないよう修正。
* ヘッダーの種類、固定表示、スクロール時の切り替え手順を同梱ガイドに追加。

= 2.0.1 =
* WordPress標準の更新画面でGitHub配布版を確認・適用できる更新機能を追加。配布元・必要環境とZIPのSHA-256を検証します。
* v2のメニュー、見本のモーション、公開側の操作と配布ファイル検査を修正。
* 見本のNewsを通常投稿の新着3件に修正。アーカイブ・検索結果の記事一覧は対象のクエリーを引き続き使います。
* 保存済みの本文・テンプレート・Global Stylesを更新時に一括変更しません。
