# デザインの変更方法

animewp は「全体の設定 → 部品の共通設定 → 1か所だけの設定 → CSS」の順に上書きできます。上の段で変えた値は、下の段で個別に指定していない場所すべてに反映されます。どの段もWordPress標準の保存先を使うため、テーマを更新しても変更は残ります。

| 段 | 場所 | 例 |
| --- | --- | --- |
| 1. 配色を選ぶ | 外観 → エディター → スタイル → パレット | 白黒（初期）・夜空・桜・青空・夕暮れ |
| 2. 色・書体を変える | スタイル → 色／タイポグラフィ | 「強調」を作品の色に、見出しを明朝に |
| 3. テキスト・区画のスタイルを変える | スタイル → ブロック → 段落／見出し／グループ → 各スタイル | 「英字ラベル」の書体と字間、「カード」の角丸 |
| 4. 1つのブロックだけ変える | 編集画面の右側の設定 | この見出しだけ大きく |
| 5. CSSで細部を変える | スタイル → 追加CSS（全体、またはブロックごと） | 下記の変数・クラス |

## 色の役割

配色はすべて次の8つの役割でできています。配色を切り替えても役割は同じなので、どの部品も同じ関係のまま色が変わります。

| 役割 | 変数 | 用途 |
| --- | --- | --- |
| 基本背景 | `--wp--preset--color--base` | ページの背景 |
| 淡い背景 | `--wp--preset--color--surface` | カード・帯・淡い区画 |
| 基本文字・濃い面 | `--wp--preset--color--contrast` | 本文、濃い区画の背景 |
| 補助文字 | `--wp--preset--color--muted` | 日付・キャプション |
| 強調 | `--wp--preset--color--accent` | ボタン・強調線 |
| 罫線 | `--wp--preset--color--border` | 区切り線・枠 |
| 強調面の文字 | `--wp--preset--color--on-accent` | ボタンの文字 |
| 濃い面の文字 | `--wp--preset--color--on-contrast` | 濃い区画の文字 |

## テキストスタイル

段落・見出しを選び、右側の「スタイル」から選びます。書体・大きさ・字間・色は「スタイル → ブロック → 段落（または見出し）」の各スタイルで一括変更できます。

| スタイル | 対象 | 初期値 |
| --- | --- | --- |
| 補助見出し | 段落 | 0.875rem、字間0.12em |
| 英字ラベル | 段落・見出し | 等幅、大文字、字間0.16em |
| リード文 | 段落 | リードサイズ、行間2 |
| キャッチコピー | 段落・見出し | 明朝、字間0.08em |
| キャプション | 段落 | キャプションサイズ、補助文字色 |
| 文字の背景ハイライト | 段落 | 淡い背景の帯 |
| 大見出し（明朝・広い字間） | 見出し | 明朝、細字、字間0.08em |
| 英字見出し | 見出し・段落 | 欧文セリフ、字間0.04em |
| 縦書き見出し（短文向け） | 見出し | 縦書き（幅781px以下は横書き） |

## 区画のスタイル

グループ・カラムに使います。背景・文字色・余白・枠を「スタイル → ブロック → グループ」の各スタイルで変更できます。淡い背景／カード／細いフレーム／濃い面／強調色の面／すりガラス／淡い色面。

## 色・書体以外の値（CSS変数）

角丸・線の太さ・動きの速さなど、スタイル画面に設定欄がない値はCSS変数です。「スタイル → 追加CSS」で上書きします。

```css
:root {
  --wp--custom--animewp--radius--small: 0;        /* カード・ボタンの角丸 */
  --wp--custom--animewp--line: 2px;               /* 罫線の太さ */
  --wp--custom--animewp--section-space: 8rem;     /* 区画の上下余白 */
  --wp--custom--animewp--motion--duration--base: 600ms; /* 表示の動きの長さ */
}
```

| 変数 | 初期値 |
| --- | --- |
| `--wp--custom--animewp--radius--small` / `--medium` / `--pill` | 4px / 18px / 999px |
| `--wp--custom--animewp--line` | 1px |
| `--wp--custom--animewp--section-space` | clamp(3rem, 7vw, 6rem) |
| `--wp--custom--animewp--header-height` | 5rem |
| `--wp--custom--animewp--motion--duration--fast` / `--base` / `--slow` | 160ms / 450ms / 900ms |
| `--wp--custom--animewp--motion--easing--out` / `--in-out` | cubic-bezier(0.2, 0.7, 0.2, 1) / cubic-bezier(0.65, 0, 0.35, 1) |
| `--wp--custom--animewp--motion--distance` / `--blur` / `--stagger` | 1.5rem / 8px / 90ms |

## 動き

動きは任意です。どのブロックにも右側の設定に「モーション」があり、登場・ホバー・動き続ける・パララックス・スクロール後の表示を選べます。グループで「中のブロックに1つずつ順に」を選ぶと、中身がまとめて順番に動きます。

サイト全体の速さは下の変数で一括変更できます。ページ間の移動には、対応ブラウザーで控えめなフェードが付きます（不要なら追加CSSに `@view-transition { navigation: none; }`）。端末で動きを減らす設定をした訪問者には、どちらも動きなしで表示します。

```css
:root {
  --wp--custom--animewp--motion--duration--slow: 1200ms; /* 登場の長さ */
  --wp--custom--animewp--motion--stagger: 150ms;         /* 順番に現れる間隔 */
  --wp--custom--animewp--motion--distance: 3rem;         /* 浮かぶ・スライドの距離 */
}
```


## 個別に追加できるパーツ（コンポーネントライブラリ）

ページやセクションの一部を、作り直さずに追加できるパターンを用意しています。投稿や固定ページ、サイトエディターで **左上「＋」→ パターン** を開いて使います。

| 挿入するもの | パターンのカテゴリー | 例 |
| --- | --- | --- |
| ページ全体 | `animewp：ページの見本` | シンプル、ぼかし、花びらの作品紹介 |
| 大きな区画 | `animewp：区画の見本` | キャラクター、スタッフ、放送情報、ニュース |
| **小さな部品** | **`animewp：個別のパーツ`** | 英日2段見出し、1枚のカバー、ガラス風タイトル、各話紹介、楽曲カード、表、動画カード、ボタン |
| **組み合わせた部品** | **`animewp：組み合わせパーツ`** | 画像＋紹介文、キャラクタープロフィール、映像カルーセル、ロゴ＋サイト名、ナビゲーション、フッター案内 |
| **装飾のある一式** | **`animewp：装飾付きの演出`** | 花びら付きキービジュアル、映像、締めくくり |
| ヘッダー・フッターの共通パーツ | `animewp：ヘッダー` / `animewp：フッター` | テンプレートパーツの「置き換え」から選ぶ |

新しい個別パーツは **既存の大きなパターンに含まれるブロックをそのまま取り出したもの**です。別のCSSや固定色・フォントを持たず、同じ `is-style-animewp-*` のブロックスタイル、テーマの配色・書体・レイアウトを使います。複数のバリエーションで中身を共有することで、サンプルと小さな部品の見た目がずれにくい構成です。

### 挿入と編集の考え方

1. 目的の「ページ」「区画」「パーツ」を挿入し、左上の **リスト表示** で入れ子のブロックを確認します。
2. 必要なところだけ画像、テキスト、URL、色を置き換えます。人物紹介・楽曲カードなどはブロックメニューから **複製** すれば、同じデザインを繰り返せます。
3. 見出しやカードはスタイル画面の共通の色・文字サイズ・余白を使い、サイト全体のテーマ変更にも追従させます。特定ページだけの色変更は個別ブロックで行えます。
4. 挿入したパターンは **通常の編集可能なブロックに展開**されます。参照元の見本を書き換えても、過去に編集・保存したページを勝手に変更することはありません。

英日見出し、各話カード、テーブル、楽曲カードなどは WordPress Core ブロックで作られているので、AnimeWP Blocksを停止しても編集できます。動画カルーセル・花びらを伴うものなどは、対応する AnimeWP Blocks が有効な場合だけ候補に表示します。装飾用の花びら・星は `装飾` ブロック単体でも追加できます。

**注意：** 各パーツ内の見本用URL（`#`、`#news` など）と画像は公開前に置き換えてください。ページ内移動先のIDは利用するページごとに確認します。ロゴ・サイト名・フッターなどは、本来のテンプレートパーツの内側で配置する方が適切です。

### カバーとヘッダーを組み合わせる場合

「キービジュアルを見せるヘッダー」はテンプレートパーツ、「花びら付きキービジュアル」はページ本文に入れるパターンです。**それぞれ別々に選べます。** 本文の最初のカバー／カルーセルを通過したらヘッダーを切り替えるため、カバーの手前に小さな別のカバーを置くと切り替え基準が変わる点に注意してください。装飾ブロックはカバーやセクションの中に配置します。

## ヘッダー

### 種類を選ぶ

サイトエディターでヘッダーを選び、ツールバーの「置き換え」から7種類を選べます。

| 種類 | 特徴 |
| --- | --- |
| 上部メニュー | 標準。狭い画面ではメニューがハンバーガーになります |
| ページ内メニュー | 区画（ストーリー、映像など）へのリンク付き |
| 全面表示メニュー | どの画面幅でもハンバーガー |
| 透ける上部メニュー | すりガラス風で、スクロールしても上に残ります |
| キービジュアルを見せるメニュー | 最初は右上の小さなメニューボタン。カバーを通過したら、ロゴ・サイト名のない細い半透明のメニューになります |
| 左固定・右固定メニュー | 1001px以上では画面の横に固定され、本文がその分ずれます。1000px以下では上部メニューになります |

ロゴ、サイト名、メニューの間には画像や、AnimeWP Blocks の装飾（花びらなど）も置けます。装飾はヘッダーの中を基準に配置されます。

### 最初は作品の画像を見せる

カバー画像に作品名が入っているページには、新しい「キービジュアルを見せるヘッダー」を使えます。テーマを更新するだけでは既存のヘッダーを置き換えないので、使いたいページのテンプレートで選びます。

1. 外観 → エディターで、トップページなど対象のテンプレートを開く。
2. ヘッダーのテンプレートパーツを選び、「置き換え」から「キービジュアルを見せるヘッダー」を選ぶ。パターン一覧では「ヘッダー：キービジュアルを見せるメニュー」という名前です。
3. 左上の「リスト表示」を開き、「スクロールで切り替えるヘッダー」の中にある「ヘッダーメニュー」を選ぶ。今まで使っていたメニューを選び直すか、リンク先を編集する。
4. 一番外側の「スクロールで切り替えるヘッダー」を選び、「モーション」の設定を確認する。初期値は「メニューを展開する」「キービジュアルを通過した後」です。
5. 保存し、公開側のプレビューで確認する。編集画面ではリンクを編集できるよう、横並びのメニューを表示します。

表示は次のように変わります。

| 状態 | 見え方 |
| --- | --- |
| ページの先頭 | 右上に小さな「メニュー」ボタン。全幅の帯は出さず、カバー画像に重ねます |
| キービジュアルを通過した後 | 半透明の細い帯とナビゲーションを表示。スマートフォンは引き続きメニューボタンです |
| メニューを開いたとき | 読みやすい不透明な背景で全面表示。開いている間や操作中は表示を切り替えません。画面幅が変わっても、キーボードで選んでいるリンクは隠しません |
| ページの先頭へ戻ったとき | 小さなメニューボタンに戻ります |

最初のボタンとスクロール後のリンクは、**同じ1つのナビゲーションブロック**です。メニューを二重に編集する必要はありません。ロゴ・サイト名のブロックは含まず、ヘッダーの表示切り替えで本文の位置も動きません。別のヘッダーからロゴとサイト名だけを外す場合は、リスト表示でその2つのブロックを削除し、「ナビゲーション」を残します。サイト名の文字列そのものを空にする必要はありません。

スクロールでの切り替えには AnimeWP Blocks が必要です。プラグインやJavaScriptが動かない場合、またはページに対象のキービジュアルがない場合は、リンクを最初から表示します。端末の「視差効果を減らす」などの設定が有効なときは、アニメーションせずに切り替えます。

### 透け方と高さを調整する

「キービジュアルを見せるヘッダー」の一番外側のグループを選び、右側の「ヘッダーの見た目」で変更します。

| 設定 | 初期値 | 調整の目安 |
| --- | --- | --- |
| 背景の不透明度（%） | 76 | 小さくすると絵がよく透けます。100なら不透明です |
| 背景のぼかし（px） | 14 | 0ならぼかしなし。絵の細部が文字に重なるときは大きくします |
| 最小の高さ（px） | 56 | 余白を増やすときは大きくします。リンクやボタンの操作領域は確保されます |

新しいヘッダーのメニューボタンにはテーマの強調色で描いた小さな花びら形のアクセントを付けました。カバーや区画に置いた花びらのアニメーションとは独立し、固定メニューには新しい浮遊アニメーションを追加しません。不要なら一番外側のグループの「高度な設定 → 追加CSSクラス」から `animewp-header--petal` を削除できます。装飾ブロックはヘッダーの中ではなくカバーや本文区画に置くと、メニューの操作領域を遮りません。

ヘッダーは最初の描画からカバーに重なり、JavaScriptが読み込まれた瞬間の上下ずれを防ぎます。JavaScriptやプラグインを停止した場合は、背景付きの通常ナビゲーションを残します。

透過するのは背景だけで、文字やボタン全体を薄くしません。背景の初期値は選択中の配色の「基本背景」です。ヘッダーのグループの「色 → 背景」から単色を選ぶと、その色に不透明度が適用され、編集画面でも同じ色でプレビューできます。文字色もブロック標準の「色」で変えられます。最初に帯を隠す見せ方には単色を使ってください。グラデーションはWordPressの背景設定をそのまま表示します。

メニューの全面表示は不透明なままにし、背景色と文字色を変える場合はナビゲーションブロックのオーバーレイの色を設定します。ぼかしに対応しないブラウザーは不透明な背景で表示します。

CSSで拡張する場合、設定値は `--animewp-header-opacity`、`--animewp-header-blur`、`--animewp-header-height` という変数として各ブロックに出力されます。透け方や高さの変更は上の設定欄から行います。

### 上に残す

ヘッダーのグループを選び、「位置 → 固定」にすると、スクロールしても上に残ります。透ける上部メニューは最初から固定です。

- ページ内リンク（`#news` など）の移動先は、ヘッダーの実際の高さだけ下にずれるので、見出しが隠れません。ロゴや画像でヘッダーが高くなっても追従します。
- 背景が透明なまま固定にすると、本文がヘッダーの下に透けて重なります。背景色を付けるか、透ける上部メニューを使ってください。
- JavaScript が動かない環境では、`--wp--custom--animewp--header-height`（最低88px）の分だけずれます。

### スクロールで切り替える

AnimeWP Blocks を使うと、ヘッダーの中のブロックごとに、右側の「モーション → 下にスクロールした後」で見え方を変えられます。上まで戻すと元に戻ります。

| 設定 | 動き |
| --- | --- |
| 隠す | スクロールしたら隠れます |
| 表示する（ページ上部では隠す） | スクロールしたら現れます |
| コンパクトにする | ヘッダーの上下の余白と高さを詰めます |
| メニューを展開する | 「キービジュアルを見せるヘッダー」のメニューボタンを、横並びのリンクへ切り替えます |

「切り替えのきっかけ」もブロックごとに設定できます。64px固定ではありません。

| 基準 | 設定方法 |
| --- | --- |
| スクロール距離 | 「スクロール距離（px）」に入力した距離を超えると切り替わります。たとえば400なら400pxを超えてから表示します |
| キービジュアルを通過した後 | 本文の最初のカルーセル、またはカバーの下端が画面上端を通過すると切り替わります。ログイン時は管理バーの下端を基準にし、画像の高さや画面幅の変更にも追従します |

従来の設定を保存済みのブロックは、距離を変更しなければ今までと同じ64pxで切り替わります。「キービジュアルを見せるヘッダー」の初期値はカバーを基準にするため、少しスクロールしただけで帯が出ることはありません。

例：ページ上部では横並びのメニュー、スクロールしたらハンバーガーにする。

1. ヘッダーを「位置 → 固定」にする
2. 横並びのメニューに「隠す」を付ける。スマートフォンで折り返さないよう、このメニューの「オーバーレイメニュー」は「モバイル」のままにします
3. もう1つメニューを置き、「オーバーレイメニュー」を「常に」にして「表示する（ページ上部では隠す）」を付ける
4. 必要ならヘッダーのグループに「コンパクトにする」を付ける

同じ方法で、正式ロゴを隠して短いロゴを表示する、といった切り替えもできます。隠れているブロックはキーボードの移動先にもならないので、操作の邪魔になりません。

## 1.xからの互換

1.xの色見本（「（従来互換）」の6色と用途別ラベル色）と「用途：」の3書体は選択肢から外しました。保存済みの本文で使われている場合は `assets/css/compat.css` が同じ見た目を保ちます。1.xの「外観 → animewp 書体」の設定は引き続き適用され、外観 → テーマの案内から解除できます。
