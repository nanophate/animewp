animewp 導入・更新手順

1. 導入前

既存サイトでは、データベースと wp-content（アップロード、テーマ、プラグイン）をバックアップし、複製した検証環境で先に表示を確認してください。

最低対象は WordPress 6.6 / PHP 8.0。WordPress 6.6 / PHP 8.0.30 と WordPress 7.1.2 / PHP 8.3.35 で実ZIPの導入・更新、iframe内の編集・保存・再読込を確認しています。各環境でバックエンド42項目、HTTP9項目、表示18項目、ブロック保存・変換42ケースが合格しました。詳しい実測範囲と未実施項目は docs/verification.md を参照してください。

2. テーマをインストール

管理画面 → 外観 → テーマ → 新しいテーマを追加 → テーマのアップロードで animewp-1.0.0.zip を選び、インストールして有効化します。親テーマや有料ビルダーは不要です。

有効化だけではページの作成、既存記事の上書き、公開、メニューやホーム設定の変更を行いません。すでに固定ホームを設定している場合は、その設定を引き続き使います。

3. 任意プラグイン

標準ブロックだけで作る場合は導入不要です。装飾パネル、独自の画像配置、動画ダイアログが必要な場合は、プラグイン → 新規プラグインを追加 → プラグインのアップロードで animewp-blocks-1.0.0.zip を選び、有効化します。

プラグインの有効化・停止・削除で投稿や設定は変更しません。テーマとプラグインのZIPは別々のアップロード画面へ入れてください。

4. 見本を下書きへ追加

外観 → animewp をはじめるで見本をプレビューします。必要な構成を選び、「下書きとして追加・開く」を押します。既存ページへの上書きは行いません。同じ見本を再実行すると前に作ったページを開きます。

作品名、文章、画像、代替テキスト、リンク、クレジット、法務情報を差し替えます。仮画像と仮文言を残して公開しないよう確認してください。問い合わせ用の送信処理は同梱しません。運用に合う連絡先またはフォームを設定します。

リスト表示でセクションや列を移動・追加・削除できます。セクションを複製した場合はHTMLアンカーを重複しない名前に変更し、メニューのリンク先も合わせます。LPのページ内リンクを別のページから使う場合は、LPのアドレスとアンカーを組み合わせます。

5. サイト全体の編集

外観 → エディターでサイト名、ロゴ、メニュー、色、書体、幅、余白を編集します。上・左・右・オーバーレイのメニューはヘッダーパターンやページのテンプレートから選択できます。

LPをホームにする場合は、内容を確認してから公開し、設定 → 表示設定で自分で選びます。取り込み操作だけではホームにはなりません。

6. 更新

更新後はキャッシュプラグインや配信側のキャッシュを削除し、ログアウト状態でも確認します。

更新前にバックアップし、更新版を検証環境へ導入します。同名のテーマまたはプラグインZIPをアップロードし、WordPressの確認画面で置き換えます。配布ファイルを直接編集した変更は置き換えられるので、編集は標準のサイトエディターと投稿編集を基本にしてください。

投稿本文・画像・既存メニューはデータベースやメディアライブラリに残ります。サイトエディターで保存したテンプレートやテンプレートパーツは、更新されたテーマの初期ファイルより優先されます。そのため、新しい初期デザインが自動では反映されない場合があります。保存済みの独自設定を確認し、必要な場合だけ個別に変更をクリアしてください。

7. プラグイン停止と内容の移行

停止後も保存HTML、本文、通常の画像・動画は残り、独自装飾とダイアログ機能は外れます。編集を続ける場合は停止前に独自ブロックの変換メニューから標準グループ等へ変換する方法を推奨します。事前に投稿を複製して、画像、リンク、字幕、本文を比較してください。

停止済みなら一時的に再有効化して変換できます。未対応ブロックとして表示された際に、内容を確認せず削除しないでください。変換によるレイアウト差や独自設定の扱いは plugins/animewp-blocks/README.md に記載しています。

8. ZIPとハッシュ

ソースから作る場合はリポジトリのルートで python3 scripts/validate.py、続いて python3 scripts/package.py を実行します。artifacts/releases/ に2つのインストールZIPと SHA256SUMS を生成します。

そのフォルダーで shasum -a 256 -c SHA256SUMS を実行すると一致を確認できます。tests/、.testenv/、artifacts/ をWordPressへアップロードする必要はありません。
