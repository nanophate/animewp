animewp 1.1.0 導入・更新手順

1. 導入前

既存サイトでは、データベースと wp-content（アップロード、テーマ、プラグイン）をバックアップし、複製した検証環境で先に表示を確認してください。

最低対象は WordPress 6.6 / PHP 8.0。バージョンごとの実測範囲と未実施項目は docs/verification.md を参照してください。

日本語で編集するには「設定 → 一般 → サイトの言語」を「日本語」にします。管理画面はユーザー別の設定が優先されるため、「ユーザー → プロフィール → 言語」も「日本語」または「サイトのデフォルト」にしてください。WordPress標準のメニュー、ブロック、ツールバーなどはWordPress本体の翻訳と言語設定に従います。テーマはこれらの設定を自動変更しません。

2. テーマをインストール

管理画面 → 外観 → テーマ → 新しいテーマを追加 → テーマのアップロードで animewp-1.1.0.zip を選び、インストールして有効化します。親テーマや有料ビルダーは不要です。

有効化だけではページの作成、既存記事の上書き、公開、メニューやホーム設定の変更を行いません。すでに固定ホームを設定している場合は、その設定を引き続き使います。

3. 任意プラグイン

標準ブロックだけで作る場合は導入不要です。装飾パネル、文字グループの傾き、独自の画像配置、動画ダイアログが必要な場合は、プラグイン → 新規プラグインを追加 → プラグインのアップロードで animewp-blocks-1.1.0.zip を選び、有効化します。

プラグインの有効化・停止・削除で投稿や設定は変更しません。テーマとプラグインのZIPは別々のアップロード画面へ入れてください。

4. 見本を下書きへ追加

外観 → animewp をはじめるで見本をプレビューします。必要な構成を選び、「下書きとして追加・開く」を押します。既存ページへの上書きは行いません。同じ見本を再実行すると前に作ったページを開きます。

作品名、文章、画像、代替テキスト、リンク、クレジット、法務情報を差し替えます。仮画像と仮文言を残して公開しないよう確認してください。問い合わせ用の送信処理は同梱しません。運用に合う連絡先またはフォームを設定します。

リスト表示でセクションや列を移動・追加・削除できます。セクションを複製した場合はHTMLアンカーを重複しない名前に変更し、メニューのリンク先も合わせます。LPのページ内リンクを別のページから使う場合は、LPのアドレスとアンカーを組み合わせます。

5. パターン・テンプレート・スタイルを選ぶ

パターンは、編集画面の「＋ → パターン」から挿入します。「animewp：ページ」はページ全体の見本、「animewp：ページの部品」はメイン画像、人物カード、お知らせ、映像など、「animewp：ヘッダー」はメニューの見本です。挿入後は標準の見出し・段落・画像などを個別に編集できます。テーマの見本は補助プラグインなしでも使えます。

テンプレートはページ全体の枠組みです。固定ページの設定にある「テンプレート」から選びます。「animewp：作品紹介ページ（ページ内メニュー）」は1ページ内の各項目へ移動する構成、「animewp：自由な全面レイアウト」はページタイトルを自動表示せず本文を全面に配置する構成です。左固定・右固定・全面表示メニューのテンプレートも用意しています。左・右固定メニューは広い画面用で、狭い画面では上部に表示します。

外観 → エディターでは、サイト名、ロゴ、メニュー、テンプレートとヘッダー・フッターを編集します。テンプレートや共通パーツ自体の編集は、それを使うほかのページにも反映されます。特定のページだけ変える場合は、そのページの本文または専用のテンプレートを編集してください。

サイト全体のスタイルは「外観 → エディター → スタイル」から選びます。「見出しを明朝に」は見出しの書体を変え、「ゆったり余白・丸いボタン」はブロック間の余白とボタンの形を変えます。選んだ後に色、幅、余白などを調整できます。

ブロック単位のスタイルは、対象ブロックを選び、ブロック設定の「スタイル」から選びます。グループには「カード」「淡い背景」、見出しには「縦書き見出し（短文向け）」、段落には「小さな補助見出し」「文字の背景ハイライト」、詳細には「開閉カード」、画像には「人物画像」があり、いずれも「animewp：」の名前で表示します。選択したブロックによって選べるスタイルが変わります。

LPをホームにする場合は、内容を確認してから公開し、設定 → 表示設定で自分で選びます。取り込み操作だけではホームにはなりません。

6. 書体と日本語の表示

サイト全体の書体・文字サイズは「スタイル → タイポグラフィ」で、個々の見出しや段落は対象ブロックの「タイポグラフィ」で選びます。設定項目が隠れている場合は、そのパネルのオプションから「フォント」などを表示してください。

「端末標準ゴシック」は本文の初期書体です。「端末標準明朝」は明朝系の書体を使います。どちらも端末にあるフォントを順に使う指定で、フォントファイルの同梱、外部フォントの読み込み、フォントの自動ダウンロードは行いません。端末に同じ書体がなければ代替書体になるため、Windows・macOS・スマートフォンで文字の形、太さ、改行位置が変わる場合があります。

「縦書き見出し（短文向け）」は短い見出しの演出用です。幅781px以下では横書きに戻ります。長い本文の縦組みやルビの細かな組版調整は対象外です。英数字・句読点・ルビを使う場合も、実際の端末とブラウザーで表示を確認してください。

7. 背景と文字グループを別々にデザインする

標準のカバーやグループで背景画像・背景色・余白を設定し、内側の見出しや段落で文字色・書体・大きさを設定します。リスト表示で親の背景ブロックと子の文章ブロックを選び分けてください。

AnimeWP Blocksを有効にすると「AnimeWP 文字グループ」で複数の見出しや段落をまとめて傾けられます。装飾パネルの中へ文字グループを挿入し、傾けたい文章だけをその中に入れます。水平に残したい本文は、同じパネルの中で文字グループの外側に置きます。

見本から始めるには「＋ → パターン → AnimeWP ブロック」で「背景と傾いた見出し・水平本文」または「角度の違う2つの文字グループ」を選びます。前者は背景・見出し・水平な本文を分ける例、後者は2つの文字グループを別の角度にする例です。どちらもモバイル用の文字角度は0度です。

背景と文字を独立させるときは「パネル全体の回転（度）」を0のままにします。装飾背景を有効にして「装飾背景だけの回転（度）」や「装飾背景だけの傾斜（度）」で背景の向きを変えます。親のパネル全体を回すと、内側の文字グループが0度でも本文を含めて一緒に回るためです。

文字グループの「文字グループの回転」パネルで、「この文字グループの回転（度）」と「モバイルの回転（度）」を設定します。どちらも -8度〜8度、初期値は0度です。幅782px以上では前者、781px以下ではモバイル用の角度を使います。モバイル用は0度を基本に、狭い画面のプレビューで読みやすさを確認してください。文字そのものの横幅・行間は内側の見出しや段落で調整します。既存ページの文章を自動的に文字グループへ移すことはありません。

8. 更新

更新後はキャッシュプラグインや配信側のキャッシュを削除し、ログアウト状態でも確認します。

更新前にバックアップし、更新版を検証環境へ導入します。同名のテーマまたはプラグインZIPをアップロードし、WordPressの確認画面で置き換えます。配布ファイルを直接編集した変更は置き換えられるので、編集は標準のサイトエディターと投稿編集を基本にしてください。

投稿本文・画像・既存メニューはデータベースやメディアライブラリに残ります。サイトエディターで保存したテンプレートやテンプレートパーツは、更新されたテーマの初期ファイルより優先されます。そのため、新しい初期デザインが自動では反映されない場合があります。保存済みの独自設定を確認し、必要な場合だけ個別に変更をクリアしてください。

9. プラグイン停止と内容の移行

停止後も保存HTML、本文、通常の画像・動画は残り、独自装飾とダイアログ機能は外れます。編集を続ける場合は停止前に独自ブロックの変換メニューから標準グループ等へ変換する方法を推奨します。事前に投稿を複製して、画像、リンク、字幕、本文を比較してください。

停止済みなら一時的に再有効化して変換できます。未対応ブロックとして表示された際に、内容を確認せず削除しないでください。変換によるレイアウト差や独自設定の扱いは plugins/animewp-blocks/README.md に記載しています。

10. ZIPとハッシュ

ソースから作る場合はリポジトリのルートで python3 scripts/validate.py、続いて python3 scripts/package.py を実行します。artifacts/releases/ に2つのインストールZIPと SHA256SUMS を生成します。

そのフォルダーで shasum -a 256 -c SHA256SUMS を実行すると一致を確認できます。tests/、.testenv/、artifacts/ をWordPressへアップロードする必要はありません。
