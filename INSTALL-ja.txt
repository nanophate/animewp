animewp 2.0.1 導入・更新手順

1. 導入前

既存サイトでは、データベースと wp-content（アップロード、テーマ、プラグイン）をバックアップし、複製した検証環境で先に表示を確認してください。

最低対象は WordPress 6.6 / PHP 8.0。バージョンごとの実測範囲と未実施項目は docs/verification.md を参照してください。

日本語で編集するには「設定 → 一般 → サイトの言語」を「日本語」にします。管理画面はユーザー別の設定が優先されるため、「ユーザー → プロフィール → 言語」も「日本語」または「サイトのデフォルト」にしてください。WordPress標準のメニュー、ブロック、ツールバーなどはWordPress本体の翻訳と言語設定に従います。テーマはこれらの設定を自動変更しません。

2. テーマをインストール

管理画面 → 外観 → テーマ → 新しいテーマを追加 → テーマのアップロードで animewp-2.0.1.zip を選び、インストールして有効化します。親テーマや有料ビルダーは不要です。

有効化だけではページの作成、既存記事の上書き、公開、メニューやホーム設定の変更を行いません。すでに固定ホームを設定している場合は、その設定を引き続き使います。

3. 任意プラグイン

標準ブロックだけで作る場合は導入不要です。装飾パネル、文字グループの傾き、独自の画像配置、動画ダイアログが必要な場合は、プラグイン → 新規プラグインを追加 → プラグインのアップロードで animewp-blocks-2.0.1.zip を選び、有効化します。

プラグインの有効化・停止・削除で投稿や設定は変更しません。テーマとプラグインのZIPは別々のアップロード画面へ入れてください。

4. 見本を下書きへ追加

外観 → animewp をはじめるで見本をプレビューします。必要な構成を選び、「下書きとして追加・開く」を押します。既存ページへの上書きは行いません。同じ見本を再実行すると前に作ったページを開きます。

作品名、文章、画像、代替テキスト、リンク、クレジット、法務情報を差し替えます。仮画像と仮文言を残して公開しないよう確認してください。問い合わせ用の送信処理は同梱しません。運用に合う連絡先またはフォームを設定します。

リスト表示でセクションや列を移動・追加・削除できます。セクションを複製した場合はHTMLアンカーを重複しない名前に変更し、メニューのリンク先も合わせます。LPのページ内リンクを別のページから使う場合は、LPのアドレスとアンカーを組み合わせます。

5. パターン・テンプレート・スタイルを選ぶ

パターンは、編集画面の「＋ → パターン」から挿入します。

見本は15種類です。どれも同じテキストスタイル・区画のスタイル・色の役割で作っているため、配色や書体を変えるとすべてが一緒に変わります。挿入後は見出し・段落・画像・ボタンなどを1つずつ選んで編集・移動・削除できます。

| 分類 | 見本 |
| --- | --- |
| animewp：区画の見本（10） | キービジュアル、作品紹介、ストーリー、映像、キャラクター、スタッフ・キャスト、音楽、放送・配信、お知らせ、締めくくり |
| animewp：ページの見本（5） | テーマだけで作る、シンプル、ぼかしから現れる、花びらが舞う、スタイル見本（すべての部品と動き） |

「テーマだけで作る」は補助プラグインなしで使えます。カルーセル・動画カード・背景レイヤー・装飾を含む見本は、必要なブロックが有効なときだけ一覧に表示します。この15種に加え、お問い合わせ・ご利用についての案内ページを用意しています。見本の文章と画像は仮のものです。公開前に差し替えてください。

「animewp：ヘッダー」「animewp：フッター」はメニューと下部の見本です。

テンプレートはページ全体の枠組みです。固定ページの設定にある「テンプレート」から選びます。「animewp：作品紹介ページ（ページ内メニュー）」は1ページ内の各項目へ移動する構成、「animewp：自由な全面レイアウト」はページタイトルを自動表示せず本文を全面に配置する構成です。左固定・右固定・全面表示メニューのテンプレートも用意しています。左・右固定メニューは広い画面用で、狭い画面では上部に表示します。

外観 → エディターでは、サイト名、ロゴ、メニュー、テンプレートとヘッダー・フッターを編集します。テンプレートや共通パーツ自体の編集は、それを使うほかのページにも反映されます。特定のページだけ変える場合は、そのページの本文または専用のテンプレートを編集してください。

区画の外枠幅はブロックツールバーの配置で通常・幅広・全幅から選びます。内側の本文幅はグループのレイアウト設定、文字の左・中央・右揃えは各見出しや段落の設定で調整します。横並び・縦並びや配置はグループのRow／Stackで変更します。画面いっぱいの区画は本文直下に置いてください。狭い親グループ内にある区画の全幅は、親が使える幅までです。

共通ヘッダーのロゴ、サイト名、ナビゲーション、CTAは標準ブロックです。「外観 → エディター → デザイン → テンプレートパーツ → ヘッダー」を開き、リスト表示から編集したい要素を選びます。テンプレートパーツの変更は、それを使うページ全体に反映されます。

v2の映像見本は「動画カード」を使います。動画URL・タイトル・ボタン文言を設定し、ポスターをメディアライブラリーから選ぶか、「YouTubeのサムネイルを取り込む」でサーバーから画像を取得してメディアライブラリーへ保存します。取り込みは編集者が明示的に操作したときだけ行います。通常は公開側も再生操作後に動画サービスへ接続しますが、背景レイヤーで「表示中の動画を無音で再生」を選んだ場合は背景表示時に接続します。従来の「動画ボタン」も引き続き利用できます。

サイト全体のスタイルは「外観 → エディター → スタイル」から選びます。「見出しを明朝に」は見出しの書体を変え、「ゆったり余白・丸いボタン」はブロック間の余白とボタンの形を変えます。選んだ後に色、幅、余白などを調整できます。

ブロック単位のスタイルは、対象ブロックを選び、ブロック設定の「スタイル」から選びます。グループには「カード」「淡い背景」、見出しには「縦書き見出し（短文向け）」、段落には「小さな補助見出し」「文字の背景ハイライト」、詳細には「開閉カード」、画像には「人物画像」があり、いずれも「animewp：」の名前で表示します。選択したブロックによって選べるスタイルが変わります。

LPをホームにする場合は、内容を確認してから公開し、設定 → 表示設定で自分で選びます。取り込み操作だけではホームにはなりません。

作品紹介の文章・画像は「固定ページ → 対象ページ → 編集」で変更します。「外観 → エディター → テンプレート」は共通の外枠を編集する場所です。そこに表示される「コンテンツ」の仮文章は本文の差し込み位置を示しており、保存した本文ではありません。

6. 書体と日本語の表示

サイト全体の書体・文字サイズは「スタイル → タイポグラフィ」で、個々の見出しや段落は対象ブロックの「タイポグラフィ」で選びます。設定項目が隠れている場合は、そのパネルのオプションから「フォント」などを表示してください。

「端末標準ゴシック」は本文の初期書体です。「端末標準明朝」は明朝系の書体を使います。どちらも端末にあるフォントを順に使う指定で、フォントファイルの同梱、外部フォントの読み込み、フォントの自動ダウンロードは行いません。端末に同じ書体がなければ代替書体になるため、Windows・macOS・スマートフォンで文字の形、太さ、改行位置が変わる場合があります。

「縦書き見出し（短文向け）」は短い見出しの演出用です。幅781px以下では横書きに戻ります。長い本文の縦組みやルビの細かな組版調整は対象外です。英数字・句読点・ルビを使う場合も、実際の端末とブラウザーで表示を確認してください。

7. 背景と文字グループを別々にデザインする

標準のカバーやグループで背景画像・背景色・余白を設定し、内側の見出しや段落で文字色・書体・大きさを設定します。リスト表示で親の背景ブロックと子の文章ブロックを選び分けてください。

AnimeWP Blocksを有効にすると「回転テキスト」で複数の見出しや段落をまとめて傾けられます。装飾パネルの中へ文字グループを挿入し、傾けたい文章だけをその中に入れます。水平に残したい本文は、同じパネルの中で文字グループの外側に置きます。

見本から始めるには「＋ → パターン → AnimeWP Blocks」で「背景と傾いた見出し・水平本文」または「角度の違う2つの文字グループ」を選びます。前者は背景・見出し・水平な本文を分ける例、後者は2つの文字グループを別の角度にする例です。どちらもモバイル用の文字角度は0度です。

背景と文字を独立させるときは「パネル全体の回転（度）」を0のままにします。装飾背景を有効にして「装飾背景だけの回転（度）」や「装飾背景だけの傾斜（度）」で背景の向きを変えます。親のパネル全体を回すと、内側の文字グループが0度でも本文を含めて一緒に回るためです。

文字グループの「文字グループの回転」パネルで、「この文字グループの回転（度）」と「モバイルの回転（度）」を設定します。どちらも -8度〜8度、初期値は0度です。幅782px以上では前者、781px以下ではモバイル用の角度を使います。モバイル用は0度を基本に、狭い画面のプレビューで読みやすさを確認してください。文字そのものの横幅・行間は内側の見出しや段落で調整します。既存ページの文章を自動的に文字グループへ移すことはありません。

8. 更新

更新後はキャッシュプラグインや配信側のキャッシュを削除し、ログアウト状態でも確認します。

更新前にバックアップし、更新版を検証環境へ導入します。2.0.0以前からは最初の一回だけ、同名のテーマまたはプラグインZIPをアップロードし、WordPressの確認画面で置き換えます。配布ファイルを直接編集した変更は置き換えられるので、編集は標準のサイトエディターと投稿編集を基本にしてください。

2.0.1以降は、配布元が公開Releaseと更新JSONを公開すると、ダッシュボード → 更新、またはテーマ／プラグインの標準画面に更新が表示されます。WordPressサーバーがGitHubへ更新を問い合わせます。インストール時は必要なWordPress・PHP版とZIPのSHA-256を確認し、不一致なら置き換えを止めます。WordPress側の自動更新設定は変更しません。

更新確認には2.0.1以降のanimewpテーマかAnimeWP Blocksの少なくとも一方の有効化が必要です。両方とも無効なら、手動ZIPで更新してください。初回インストールは引き続きZIPアップロードです。WordPress.orgの検索結果に登録する仕組みではありません。

更新が出ない場合は「ダッシュボード → 更新 → もう一度確認」を使います。通常の成功キャッシュは1時間、通信失敗時の再試行間隔は5分です。直近の正常な情報は最大7日間使います。非公開リポジトリや未公開の配布版は、サイトから認証なしでは取得できません。サイトへGitHubトークンを入力する設定はありません。更新処理固有のエラーは英語で表示されます。

投稿本文・画像・既存メニューはデータベースやメディアライブラリに残ります。サイトエディターで保存したテンプレートやテンプレートパーツは、更新されたテーマの初期ファイルより優先されます。そのため、新しい初期デザインが自動では反映されない場合があります。保存済みの独自設定を確認し、必要な場合だけ個別に変更をクリアしてください。v2の作品紹介見本の標準アンカーは news / introduction / story / staff / onair です。旧ヘッダー・フッターを保存済みの場合は、残したい編集内容を保ったまま、メニューのリンク先を見本の実際のアンカーへ合わせてください。

2.0.1の新しい見本ではNewsに通常投稿の新着3件を表示します。取り込み済みのページ本文は自動で置き換えません。以前の見本でNewsに固定ページ自身が出る場合は、そのページの編集画面でNews内のクエリーループを選び、テンプレートからのクエリー継承を無効にして、投稿タイプを「投稿」に設定します。アーカイブや検索用テンプレートの一覧ではクエリー継承を維持してください。

9. プラグイン停止と内容の移行

停止後も保存HTML、本文、通常の画像・動画は残り、独自装飾とダイアログ機能は外れます。編集を続ける場合は停止前に独自ブロックの変換メニューから標準グループ等へ変換する方法を推奨します。事前に投稿を複製して、画像、リンク、字幕、本文を比較してください。

停止済みなら一時的に再有効化して変換できます。未対応ブロックとして表示された際に、内容を確認せず削除しないでください。変換によるレイアウト差や独自設定の扱いは plugins/animewp-blocks/README.md に記載しています。

10. ZIPとハッシュ

ソースから作る場合はPython 3.10以上、Node.js 24.18以上、npm 11.16以上、PHPまたはDockerを用意します。リポジトリのルートで npm ci と npm ci --prefix tests/serialization を実行し、python3 scripts/validate.py、続いて python3 scripts/package.py を実行します。artifacts/releases/ に2つのインストールZIPと SHA256SUMS を生成します。

そのフォルダーで shasum -a 256 -c SHA256SUMS を実行すると一致を確認できます。tests/、.testenv/、artifacts/ をWordPressへアップロードする必要はありません。

付録：2.0.0の書体と色

初期配色は白・黒・グレーです。外観 → エディター → スタイル → 色 → パレットで「夜空」「桜」「青空」「夕暮れ」の配色を選べます。どれも8つの色の役割（基本背景・淡い背景・基本文字・補助文字・強調・罫線・強調面の文字・濃い面の文字）だけを入れ替えるため、選んだ後も各色を自由に変更できます。外観 → エディター → スタイルで配色・タイポグラフィを設定し、個々のブロックの標準色設定で上書きできます。追加CSSからトークンを変更することもできます。装飾パネルの「色見本に追従」「色の役割に追従」は選択したサイトの色を参照します。任意色はそのブロックに固定されます。既存の色設定は更新で消えません。

書体は標準Font Libraryで追加します。WordPress 7以降は外観 → フォント、6.6は外観 → エディター → スタイル → タイポグラフィ → フォントの管理です。本文・見出しの書体は「スタイル → タイポグラフィ」、英字ラベル・キャッチコピー・大見出しなどのテキストスタイルは「スタイル → ブロック → 段落／見出し」の各スタイルで書体・大きさ・字間を変更でき、そのスタイルを使うすべての箇所に反映されます。1.xの「外観 → animewp 書体」の設定は既存の本文に引き続き適用され、外観 → テーマの案内から解除できます。フォントファイルは同梱せず、初期ダウンロードは0バイトです。

ゴミ箱にある取り込み済みページは、明示的に下書きへ復元するか、新しい下書きを追加します。復元しても自動公開しません。新規追加は元のゴミ箱ページを残します。ロックは120秒のリースで通常の同時取り込みを1件に制限します。120秒を超えて停止した古い処理が再開する場合の厳密な分散フェンシングは提供しません。

動画ファイルでは、別配信元の字幕を使う場合に匿名CORSを選び、動画・字幕両方の配信サーバー設定を確認します。外部動画はYouTubeまたは公開Vimeoを選び、接続に関する案内と元リンクを残します。標準ブロックへの変換と停止後の再保存の注意点は補助プラグインのREADME.mdを参照してください。

フッターのリンク、SNS、権利表記は見本です。実際の固定ページ・公式アカウント・権利者へ差し替えてください。RSSは標準RSSブロックでURLを設定した場合だけ使います。SNS API連携、自動転載、WP-Cronによる収集は含みません。
