# デザインの変更方法

animewp は「全体の設定 → 部品の共通設定 → 1か所だけの設定 → CSS」の順に上書きできます。上の段で変えた値は、下の段で個別に指定していない場所すべてに反映されます。どの段もWordPress標準の保存先を使うため、テーマを更新しても変更は残ります。

| 段 | 場所 | 例 |
| --- | --- | --- |
| 1. 配色を選ぶ | 外観 → エディター → スタイル → パレット | 白黒（初期）・夜空・桜・青空・夕暮れ |
| 2. 色・書体を変える | スタイル → 色／タイポグラフィ | 「強調」を作品の色に、見出しを明朝に |
| 3. テキスト・区画のスタイルを変える | スタイル → ブロック → 段落／見出し／グループ → 各スタイル | 「英字ラベル」の書体と字間、「カード」の角丸 |
| 4. 1つのブロックだけ変える | 編集画面の右側の設定 | この見出しだけ大きく |
| 5. CSSで細部を変える | スタイル → 追加CSS（全体、またはブロックごと） | 下記の変数・クラス |

## 色の役割

配色はすべて次の8つの役割でできています。配色を切り替えても役割は同じなので、どの部品も同じ関係のまま色が変わります。

| 役割 | 変数 | 用途 |
| --- | --- | --- |
| 基本背景 | `--wp--preset--color--base` | ページの背景 |
| 淡い背景 | `--wp--preset--color--surface` | カード・帯・淡い区画 |
| 基本文字・濃い面 | `--wp--preset--color--contrast` | 本文、濃い区画の背景 |
| 補助文字 | `--wp--preset--color--muted` | 日付・キャプション |
| 強調 | `--wp--preset--color--accent` | ボタン・強調線 |
| 罫線 | `--wp--preset--color--border` | 区切り線・枠 |
| 強調面の文字 | `--wp--preset--color--on-accent` | ボタンの文字 |
| 濃い面の文字 | `--wp--preset--color--on-contrast` | 濃い区画の文字 |

## テキストスタイル

段落・見出しを選び、右側の「スタイル」から選びます。書体・大きさ・字間・色は「スタイル → ブロック → 段落（または見出し）」の各スタイルで一括変更できます。

| スタイル | 対象 | 初期値 |
| --- | --- | --- |
| 補助見出し | 段落 | 0.875rem、字間0.12em |
| 英字ラベル | 段落・見出し | 等幅、大文字、字間0.16em |
| リード文 | 段落 | リードサイズ、行間2 |
| キャッチコピー | 段落・見出し | 明朝、字間0.08em |
| キャプション | 段落 | キャプションサイズ、補助文字色 |
| 文字の背景ハイライト | 段落 | 淡い背景の帯 |
| 大見出し（明朝・広い字間） | 見出し | 明朝、細字、字間0.08em |
| 英字見出し | 見出し・段落 | 欧文セリフ、字間0.04em |
| 縦書き見出し（短文向け） | 見出し | 縦書き（幅781px以下は横書き） |

## 区画のスタイル

グループ・カラムに使います。背景・文字色・余白・枠を「スタイル → ブロック → グループ」の各スタイルで変更できます。淡い背景／カード／細いフレーム／濃い面／強調色の面／すりガラス／淡い色面。

## 色・書体以外の値（CSS変数）

角丸・線の太さ・動きの速さなど、スタイル画面に設定欄がない値はCSS変数です。「スタイル → 追加CSS」で上書きします。

```css
:root {
  --wp--custom--animewp--radius--small: 0;        /* カード・ボタンの角丸 */
  --wp--custom--animewp--line: 2px;               /* 罫線の太さ */
  --wp--custom--animewp--section-space: 8rem;     /* 区画の上下余白 */
  --wp--custom--animewp--motion--duration--base: 600ms; /* 表示の動きの長さ */
}
```

| 変数 | 初期値 |
| --- | --- |
| `--wp--custom--animewp--radius--small` / `--medium` / `--pill` | 4px / 18px / 999px |
| `--wp--custom--animewp--line` | 1px |
| `--wp--custom--animewp--section-space` | clamp(3rem, 7vw, 6rem) |
| `--wp--custom--animewp--header-height` | 5rem |
| `--wp--custom--animewp--motion--duration--fast` / `--base` / `--slow` | 160ms / 450ms / 900ms |
| `--wp--custom--animewp--motion--easing--out` / `--in-out` | cubic-bezier(0.2, 0.7, 0.2, 1) / cubic-bezier(0.65, 0, 0.35, 1) |
| `--wp--custom--animewp--motion--distance` / `--blur` / `--stagger` | 1.5rem / 8px / 90ms |

## 1.xからの互換

1.xの色見本（「（従来互換）」の6色と用途別ラベル色）と「用途：」の3書体は選択肢から外しました。保存済みの本文で使われている場合は `assets/css/compat.css` が同じ見た目を保ちます。1.xの「外観 → animewp 書体」の設定は引き続き適用され、外観 → テーマの案内から解除できます。
