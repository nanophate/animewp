# animewp の設計

animewp は単独で動くブロックテーマです。任意の animewp-blocks は、標準ブロックだけでは足りない装飾・文字グループの回転・画像配置・映像ダイアログを補います。テーマは補助プラグインを呼び出さず、見本のLPも標準ブロックだけで構成します。

## 保存先と担当

- 投稿、ページ、人物紹介、告知、クレジットは通常の投稿・固定ページと標準ブロックへ保存します。
- 色、書体、間隔はサイトエディターのスタイル、メニューは標準ナビゲーションに保存します。
- テーマの templates / parts / patterns は初期値です。利用者がサイトエディターで保存した変更を更新時に消しません。
- 子テーマや有料ビルダーは必要ありません。独自のPHP関数、CSSクラス・変数、ハンドル、オプションには animewp の接頭辞を付けます。
- 補助ブロックは本文と静的HTMLを保存し、補助プラグイン停止後も内容を表示できます。編集復旧には標準ブロックへの変換を用意します。

## 初期表示と導入

front-page.html は同梱しません。既存の固定ホーム設定・メニュー・投稿を有効化で変更しません。投稿一覧のホームにはサイト名、任意のキャッチフレーズ、最新記事を表示します。

見本の導入は管理画面でのプレビューと明示操作を通し、常に新規の下書きとして作成します。取り込み済みIDの記録と排他処理で二重送信を防ぎます。公開、ホーム設定変更、既存記事への上書きは行いません。

## 編集と表示

基本の列や画像文章は標準カラム・画像・グループ、ヒーローはカバー、ニュースは単一クエリーループ、人物カードは画像・見出し・詳細ブロックです。長文は自然に折り返し、高さを固定せず、編集で文字サイズを下げる必要がありません。

メニューは標準ナビゲーションのモバイル表示・キーボード処理を使います。上下左右の構図に応じたヘッダーパターンとテンプレートを用意します。背景装飾は初期状態では無効です。

パネルの背景だけを傾ける場合は装飾背景の回転・傾斜を使います。見出しや本文のまとまりだけを回転する場合は、未回転の親パネル内に「AnimeWP 文字グループ」を置き、内側へ標準の見出し・段落・グループを入れます。兄弟ブロックは水平のままです。親全体の回転は子の座標系にも作用するため、子を0度にしても親の傾きは打ち消しません。

各パネル・文字グループの装飾用CSS変数は、各ルートで既定値を明示します。子が親の回転値を再利用して二重に回転することを防ぎます。v1.0.0パネルの保存内容を互換形式として受理し、既存の回転角度を勝手に移動・変換しません。WordPress 6.6の旧シリアライザーが不透明度に付けたpxは、編集保存時に単位なしへ正規化します。データベースの一括移行や有効化時の書き換えはしません。新しい文字グループは781px以下で既定0度になり、狭幅専用の角度も選べます。

フォントは端末標準の日本語ゴシック・明朝の候補です。フォントデータは配布しません。短い見出しの縦書きと狭幅での横書き化を備えますが、縦中横やルビなどの専用編集機能は含みません。

## 対象と試験

最低対象は WordPress 6.6 / PHP 8.0 です。実際の2環境と確認範囲は verification.md に記載し、全バージョンや全プラグインとの互換性は宣言しません。

必須の試験は、テーマだけ／補助あり／補助停止・再有効化／別テーマへ変更の各状態、実ZIP導入、編集・保存・再読込、iframeエディター、既存ホーム維持、権限・nonce・二重送信、通常テンプレートと検索0件、代表的な他プラグイン、狭幅・キーボード操作です。
