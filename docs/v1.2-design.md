# animewp 1.2.0 — 編集可能な白黒の土台

白・黒・グレーを初期状態とするブロックテーマと、任意の補助プラグインです。追加の配色スキン、着せ替え画面、独自配色インポートは含めません。作品の色は標準Global Styles、各ブロックの設定、追加CSSで付けます。元のデモは構成の参考で、画像・ロゴ・コード・作品情報を転用していません。未提供の旧v2仕様全体の実装完了は宣言しません。

## 責務

| 所有者 | 担当 |
| --- | --- |
| WordPress Core | 投稿・固定ページ・メディア・Font Library・Global Styles・Navigation・Query・Cover・Gallery拡大・Details・Table・RSS・再利用パターン |
| animewpテーマ | 白黒の初期デザイン、トークン、標準ブロックのパターン、テンプレート、任意の下書き導入、3用途のフォント割当 |
| animewp-blocks | 装飾パネル、文字グループの回転、画像と本文の配置、字幕付き動画・同意後の外部動画ダイアログ |

この版は親テーマ不要のブロックテーマです。テーマ単体で基本サイトを作れます。補助プラグインだけではテーマ一式をインストールしません。別テーマで利用する場合は対応するGutenberg機能が必要で、同じ外観・全組合せの互換性は保証しません。

37テーマパターン、2補助パターン。全体見本は3種のLP、人物、連絡先、法務の計6種です。各項目は独立した標準ブロックで追加・削除・移動できます。サイト全体のテンプレート・共通ヘッダー／フッターはSite Editor、ページ固有の文章・画像は投稿エディターで編集します。SNS API・自動転載・WP-Cron収集・送信フォーム・通販決済は含めません。

標準項目はCoreのスキーマを使用します。独自4ブロックの正確な属性・型・範囲・既定値は各`block.json`が単一の定義元です。画像の代替テキスト・キャプション・リンクも標準Imageが所有します。任意HTMLや第三者スクリプトを動画URLとして実行しません。

## トークンと優先順位

`inc/design-tokens.json`から`theme.json`を生成します。base、surface、contrast、muted、accent、border、on-accent、on-contrast、用途別ラベル色はすべて初期値がモノクロです。前6種は従来のanimewp-*色変数を参照し、過去の色変更を維持します。新しい標準色見本を個別に変えることもできます。

角丸・セクション間隔・ヘッダー高さ・装飾グラデーション・影・デュオトーンをtheme.jsonへ集約しています。幾何学的な回転、clip-path、ブレークポイントはCSSの構文値です。標準のブロック個別スタイルは局所的な指定として優先し、独自装飾は選んだプリセット変数を参照します。明示的な文字色は自動の役割前景より優先します。

追加CSSの例（任意の色に変更できます）：

```css
:root {
  --wp--preset--color--accent: #285c4e;
  --wp--preset--color--on-accent: #ffffff;
}
```

標準色見本のaccentを変更する方法でも、上のCSSでも、ボタンと選択済みの装飾背景が同じ色へ変わることを確認しました。旧本文で固定色を直接指定した箇所は自動変更しません。変更した色、画像上の文字、半透明面、個別の子ブロックは公開前にコントラストを確認してください。

## 書体

初期状態は端末標準フォントで、同梱フォントは0ファイル・0バイトです。Font Libraryで任意の書体を追加・有効化し、本文と見出しにはGlobal Styles、英字・大見出し／短いアクセント／等幅文字には任意の3役割を使えます。3は用途数で、追加フォント数の制限ではありません。日本語名、数字、アンダースコア由来のCore slugも扱います。

ブロックへ別書体を直接指定することもできます。役割に割り当てたフォントが削除・無効化された場合はフォールバックに戻り、管理画面で案内します。font-display未指定のユーザー追加faceにswapを既定として適用し、明示指定は保持します。色編集でフォントデータを変更する独自処理はありません。

## 導入と耐久性

有効化だけで投稿、メニュー、公開状態、ホーム設定、色、書体を変更しません。下書き導入は明示操作で、再実行は既存本文を保持します。ゴミ箱にあれば「下書きへ復元」「新しい下書き」を選び、自動で公開しません。通常の同時要求はDBの一意挿入で1件だけ通します。ロックは120秒のリースで、期限を超えて中断した旧処理への分散フェンシングは対象外です。

保存された1.0/1.1 HTMLを受理し、有効化や表示時のDB一括移行はありません。新規属性は既定値で保存形を変えません。停止後は静的な本文・画像・動画または外部動画リンクが残ります。編集継続には停止前の標準ブロック変換を用意します。匿名CORS動画の停止後再保存の制限は補助プラグインREADMEに記載しています。

## 操作と表示

幅781px以下ではモバイルメニュー、縦組みの横組み化、画像の別焦点、読む順に沿った縦配置を使います。ネイティブGallery／Details／Navigationを利用し、外部動画は同意ボタン後だけiframeを生成・破棄します。フォーカス表示、44pxの主要操作、低モーション、JavaScript無効時の本文・リンク、印刷時の表示を用意しています。

実測範囲と未検証は`verification.md`を参照してください。全端末、全テーマ、全外部サービスの保証はしません。
